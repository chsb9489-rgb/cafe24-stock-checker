# 📦 주문-재고 연동 및 출고 가능 여부 체크기

보유 재고 엑셀과 신규 주문 엑셀을 매칭하여, 즉시 출고 가능한 주문과 재고 부족으로
인한 출고 대기 주문을 자동으로 분리해주는 도구입니다.

---

## 🎯 주요 기능

* 보유 재고 엑셀과 신규 주문 엑셀을 자동으로 매칭합니다.
* 재고가 충분해서 **즉시 출고 가능한 주문**을 찾아줍니다.
* 재고 부족으로 **출고를 보류해야 하는 주문**을 별도로 분리해줍니다.

## 💻 사용 방법

1. **보유 재고 엑셀**을 업로드합니다.
2. **신규 주문 엑셀**을 업로드합니다.
3. 자동으로 매칭 결과가 계산됩니다.
4. 출고 가능/대기 목록을 확인하고 필요 시 다운로드합니다.

## 🛠️ 기술 스택

* **Language**: Python
* **Web Framework**: Streamlit
* **Data Processing**: Pandas, OpenPyXL

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
